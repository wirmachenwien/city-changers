City Changers / design system

Icon library.

Hand-drawn controls, social marks and decorative list markers. Every icon has a 24×24 SVG source and transparent light/dark PNG exports. Previews show 16, 24 and 40 pixel sizes.

Using the icons.

  • SVGs inherit currentColor; semantic palette tokens handle light and dark themes.
  • 96×96 PNGs use transparent backgrounds and registered ink colors. Marker PNGs use the accent token.
  • Keep icon SVGs decorative. Put accessible labels on the surrounding button or link.
  • Social silhouettes, favicons, brand logos and QR matrices keep their established geometry.
  • Edit SVG sources in drawn/ and run npm run icons:build. Do not edit generated files in src/.

The old icon archive is retained separately for reference.

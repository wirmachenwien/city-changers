# Restored element studies

[Open the visual catalogue](index.html). These are the **41 original SVG files**
discarded during the selected-set cleanup: 25 early masters/references and 16
unselected stroke variations. They were recovered unchanged from the pre-cleanup
snapshot, not redrawn. The eight selected line exports remain in the active
library; this archive does not replace them or reactivate old renderers.

The bracket trial uses an identical promoted copy at `../lines/bracket.svg`.
Archived frame/tail comments refer to the historical nine-slice renderer; these
files are references, not fixed-ratio containers for live content.
